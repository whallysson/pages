# Páginas

Páginas públicas dos projetos do Whallysson, servidas pelo GitHub Pages em https://whallysson.github.io/pages/.

- `whally/oauth-client.json`: a identidade do app Whally no login OAuth dos apps que ele conecta (Client ID Metadata Document, especificação de autorização do MCP 2026-07-28). O `client_id` é o próprio endereço do arquivo, e os endereços de volta são portas fixas do próprio Mac.
- `whally/index.html`: o que é o Whally, para a tela de permissão dos apps.

Tudo neste repositório é público: nunca guarde segredos aqui.
